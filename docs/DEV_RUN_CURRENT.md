# 当前开发版本启动规范

正式开发验收统一双击仓库根目录的 `RUN_CURRENT_TXWZS.command`。

该启动器每次实时读取当前 Git branch、7 位 commit 和 working tree
状态，固定启动 `res://scenes/blank_map.tscn`，并把场景标识设为
`CITY`。

## 窗口标题

- `main@abcdef1`：该窗口由标准启动器从对应 branch 和 commit 启动。
- `DEBUG`：当前是开发调试运行，不是正式发布构建。
- `DIRTY`：启动时工作区存在尚未提交的修改。
- `UNIDENTIFIED`：未通过标准启动器进入，不能作为当前版本验收依据。
- `CITY`：正式城市主场景。
- `BATTLE-C0`：独立 C0 战斗灰盒，不是当前正式入口。

正式验收只保留一个 `CITY` 窗口。再次双击启动器时，它只会关闭自己
登记且能同时核对仓库路径和启动凭据的旧进程，然后启动当前版本。

如果发现没有登记、但明确运行着同一仓库的游戏进程，启动器会列出
PID 和完整命令并拒绝制造第二个窗口。它不会模糊关闭 Godot 编辑器、
Project Manager、其他项目或无法确认身份的进程。

启动器状态和日志保存在 `/tmp`，不会写入项目或 Git。C0 仍需作为
独立灰盒运行，不得把该启动器视为城市到战斗的正式串联。
