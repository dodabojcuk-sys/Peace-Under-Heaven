# P0-06 统一建筑交互与右侧建造入口

## 1. 阶段结论

阶段名称：

`P0-06_UNIFIED_BUILDING_INTERACTION_AND_RIGHT_SIDE_CONSTRUCTION_ENTRY`

本阶段只解决两个相互关联的问题：

1. 建造、建筑详情和建筑上下文操作的 UI 职责统一到右侧；
2. 当前地图预置建筑与运行时测试建筑复用同一套权威记录、选择、描边和详情机制。

本阶段不实现建筑移动、批量操作、撤回或任何正式建筑功能。

## 2. 用户决定

用户已冻结以下信息架构：

- “建设”属于右侧建造入口；
- 选中建筑后的操作属于右侧上下文详情；
- “派遣”未来从军令台、军队或战役对象进入；
- “管理”必须拆成具体功能后再出现；
- 未实现的功能不显示禁用按钮或假入口；
- 当前底部“建设／派遣／管理”整组删除，不保留透明占位；
- 本阶段无需 Figma，先验证职责和交互闭环。

## 3. 当前建筑清单

当前 `MapWorld` 中有六个固定预置建筑：

| 场景节点 | 显示名称 | 当前世界 Rect | 原型说明 |
|---|---|---:|---|
| `Manor` | 城主府 L1 | `(80, 120, 190, 120)` | 城市行政中枢占位 |
| `Barracks` | 兵营 L1 | `(350, 120, 190, 120)` | 军事训练设施占位 |
| `Granary` | 粮仓 L2 | `(650, 120, 190, 120)` | 城市粮食储备占位 |
| `Academy` | 学院 L1 | `(80, 430, 190, 120)` | 研究与教育设施占位 |
| `CityGate` | 城门 L1 | `(350, 430, 190, 120)` | 城市出入口占位 |
| `CommandPlatform` | 军令台 L1 | `(650, 430, 190, 120)` | 军事命令设施占位 |

它们目前只是 `ColorRect` 灰盒节点，没有权威建筑记录、placement ID 或选择响应。

运行时测试建筑位于 `MapWorld/ConstructionLayer/PlacedBuildings`，已经拥有 P0-05 权威记录和安全移除生命周期。

## 4. 统一记录原则

不得创建 LandmarkController、第二个选择控制器、第二份详情字典或按节点名称临时猜测权限。

`ConstructionController` 继续作为唯一建筑权威所有者。固定预置建筑和运行时放置建筑使用同一种记录形状。

记录保留既有字段，并增加最小能力字段：

```text
placement_id
placement_kind        fixed / placed
template_id
display_name
building_type
description
origin_cell
footprint
occupied_footprint_cells
selection_bounds
lifecycle_state
prototype_status
selectable
removable
movable
node
```

能力规则：

| 建筑种类 | selectable | removable | movable |
|---|---:|---:|---:|
| 固定预置建筑 | true | false | false |
| 运行时测试建筑 | true | true | false |

节点 metadata 仍只保存 `placement_id`。外部通过复制后的 record getter 读取，不获得可静默修改的权威 Dictionary 引用。

## 5. placement ID 与初始化

- 启动时由 `ConstructionController` 先注册六个固定建筑；
- 固定建筑和运行时建筑共享同一个单调递增 ID 空间；
- 注册完成后，新放置测试建筑继续获得后续 ID；
- 删除运行时建筑不回收 ID；
- 固定建筑不进入普通移除生命周期；
- selection 仍只保存一个 `selected_placement_id`。

ID 是运行时身份，不承诺为正式存档 ID。

## 6. 固定建筑网格占用

固定建筑必须阻止在其可见矩形上重复建造。

由于现有灰盒矩形没有完全对齐 40 单位网格，本阶段采用保守栅格化：

1. 读取固定建筑在 MapWorld 中的真实矩形；
2. 左上角使用 `floor(rect.position / GRID_SIZE)`；
3. 右下角使用 `ceil(rect.end / GRID_SIZE)`；
4. 将所有相交网格写入 `occupied_cells`，所有权为该固定建筑 placement ID。

这会覆盖整个可见灰盒，不移动节点，也不把现有灰盒位置承诺为正式地图尺度。

固定建筑占用只用于阻止重叠建造，不获得可移除生命周期。

## 7. 统一命中与选择

`BuildingSelectionController` 不再只遍历 `PlacedBuildings` 子节点，而是按权威 `placement_order` 读取所有 `selectable=true` 的记录。

命中规则：

- 使用同一 Canvas transform 将屏幕坐标转换到世界；
- 使用记录中的节点 transform 与 `selection_bounds` 命中；
- 不依赖节点名称、显示文本或父节点路径判断能力；
- 固定 Control 灰盒和运行时 Node2D 建筑都通过 `CanvasItem` transform 处理；
- 选择结果仍只写 `selected_placement_id`。

描边继续复用唯一 `SelectionOutline`，不改变建筑本体颜色。

## 8. 统一详情

右侧详情始终从权威记录读取：

- 建筑真实名称；
- 建筑类型；
- 网格位置；
- 占地；
- 原型状态；
- 简短说明。

固定建筑：

- 显示“固定预置建筑”身份；
- 显示对应中性功能说明；
- 不显示移动或移除入口。

运行时测试建筑：

- 保留“中性测试建筑”身份；
- 保留 P0-05 “移除建筑（原型）”与确认流程；
- 不显示移动入口。

军令台和其他固定建筑走同一基础响应，不写专用点击特例。

## 9. 右侧 UI 职责

复用当前 `UI/Shell`：

- 小地图保持右上；
- 小地图下方提供明确的“建造”入口；
- 打开后只显示当前唯一“测试建筑”模板；
- 选中建筑时，同一区域切换为 280 × 360 建筑详情；
- 进入 placing 后显示简短建造状态与取消提示；
- 不创建第二套 UI Shell。

互斥规则：

1. 打开建造入口：清除当前选择和移除确认；
2. 选择模板：进入既有 placing；
3. 选中建筑：关闭建造列表或预览，显示建筑详情；
4. 关闭详情：只取消选择，不自动打开建造列表；
5. `Esc`：placing 优先取消，其次关闭建造列表，再次才取消选择；
6. UI 内点击、拖动和滚轮不穿透地图；
7. UI 隐藏后对应地图区域立即恢复交互。

不新增 `_input` 所有者。按钮只通过 GUI signal 通知现有控制器。

## 10. 底部操作栏

删除整个 `ContextBar`，包括：

- “未选择目标”；
- 临时“建造”按钮；
- “派遣”占位；
- “管理”占位；
- 分隔线和背景。

删除后不得留下：

- 空白底栏；
- 隐藏但仍接收输入的 Control；
- 建造遮挡检测中的陈旧引用；
- 测试对旧路径的依赖。

地图视口和 Camera2D clamp 不因底栏删除而重构。

## 11. 建造入口

右侧建造区域只提供真实可用内容：

- “建造”入口；
- 当前唯一“测试建筑”模板；
- placing 状态说明；
- 现有右键／Esc 取消。

不提前显示第二模板、资源成本、建造时间、分类或正式图标。

## 12. P0-05 回归保护

以下行为不得改变：

- 40 世界单位网格；
- 3 × 2 测试建筑占地；
- 有效／无效预览；
- 重复占用拒绝；
- 左键确认；
- placing 中键拖动和滚轮缩放；
- 右键／Esc 取消；
- 运行时建筑 selection、remove confirm、安全移除和原位重建；
- placement ID 删除后不复用；
- 意外离树清理；
- 唯一 `_input`。

固定建筑注册后，既有 smoke 应使用初始化后的记录和占用基线，不再假设场景启动时记录数为零。

## 15. 未来阶段记录

### P0-07：单栋建筑移动

- 从右侧详情进入移动；
- 原建筑进入移动预览；
- 确认前保留可恢复的原位置；
- 确认时原子迁移占用格；
- 保持同一个 placement ID；
- 支持取消；
- 不允许部分迁移。

### P0-08 或更后：批量模式与撤回

- 移除模式可研究单点、连续或多选；
- 批量操作必须整体校验、整体提交或整体失败；
- undo/redo 需要正式事务或命令记录；
- 撤回必须处理 placement ID、完整建筑快照、占用冲突和后续操作封口；
- 不得把新建一栋相似建筑伪装成真正撤回。

P0-05 的 placement ID 不复用规则与撤回存在设计关系，必须在实现 undo 前单独研究。

## 16. 禁止范围

- 建筑移动、批量移动或批量移除；
- 连续移除模式；
- undo/redo；
- 资源成本、返还、生产或建造时间；
- 道路、升级、人口、耐久或战斗；
- 军令台派兵或战役功能；
- 正式建筑目录、Resource 数据库或存档 schema；
- 多城市；
- 正式图标、美术、动画或视觉重做；
- 第二个 `_input`、建筑记录所有者、选择控制器或 UI Shell。
