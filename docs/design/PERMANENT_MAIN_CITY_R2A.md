# 永久主城空间经营与信息层级重构（R2A）设计冻结

状态：已冻结（本轮施工依据，不等待中途确认）
基线：`f576f0b`，分支 `codex/txwzs-permanent-city-r2a`
基线取证：`TXWZS_R2A_DELIVERY/baseline/before-{1280,1152}-default.png`、
`before-1280-selected.png`（点击民居无任何上下文 UI）、
`before-1280-recommend-autoplace.png`（推荐即静默扣粮开工）

## 1. 三类空间边界（冻结）

- **永久主城**：黑石城。全屏 MapWorld + 镜头 + 道路 + 建筑长期保留；可经营、
  建设、安置、升级。R1C 结算后回到这里。
- **本关战区**：调兵/行军/侦察/攻城/补给。不承担永久主城建设。
- **战时内城**：关卡内许可城市的临时建设，用本地兵粮，战后不占领。

任何入口、名称、资源口径不得混用三者（R1C phase-UI 已修复，本轮保持）。

## 2. 当前问题（基线取证结论）

1. 「城市经营」大右栏默认常驻展开，占据约 30% 宽度——玩家先看见表格再看见城市。
2. 点击普通民居无任何选择反馈（BuildingSelectionController 的 select_placement
   链存在但未触达，或该类建筑不可选）。
3. 推荐按钮（补充木材·伐木场）点击即静默开工并扣资源，玩家不知道建筑完成后
   还需要手动安置；`READY_TO_PLACE` 状态没有任何 UI 浮现。
4. 1152×648 下右栏与顶栏挤压城市可视面积更明显。

## 3. 三层信息架构（冻结）

### 第一层：常驻 HUD（现有顶栏，保持精简）
城市名+永久主城身份、日期/季节、核心资源、目标/最高优先预警、倍率与暂停、
战役入口。本轮只做防重叠复查，不新增顶栏内容。

### 第二层：对象上下文（点击建筑出现）
复用 `BuildingSelectionController.select_placement`：选择轮廓 + `detail_panel`
（名称/状态/核心作用/岗位/道路/现有动作）。未选中即隐藏；点击空白/Esc/关闭
按钮收起。不建第二份建筑状态。

### 第三层：城市总览（按需）
`governance_workspace`（城市经营面板）改为**默认收起、显式开关**：
顶栏「城市经营」按钮切换开/关；放置中、选模板中、详情面板打开、有建造工程时
强制收起（沿用现有条件链）；关闭后回到全屏城市。

## 4. 默认视图（冻结）

进入永久主城：全屏城市 + 顶栏 + 小地图；经营面板默认收起。
平移/缩放/命中/道路不变。

## 5. 建设与安置流程（冻结）

```
推荐/建设入口 → start_build_project（正式事务，扣料开工）
→ PRODUCING（建造中，HUD 出现工程状态）
→ READY_TO_PLACE（建造完成：HUD 出现「开始安置」浮动按钮）
→ activate_ready_placement → PLACEMENT_ACTIVE（全屏移动预览，R 旋转，
  无效位置显示原因，左键确认，右键/Esc 取消回 READY_TO_PLACE）
→ 确认生成正式建筑记录 → 点击可选中学生详情（抽屉）
→ 冷恢复后位置/等级/状态一致
```

推荐按钮改为**不再静默开工**：点击后进入对应建筑的选择态并打开建设目录，
由玩家确认开工；不得替玩家决定最终位置。
（生命周期保持"先施工、完成后安置"，不改材料/工期/返还/升级数值。）

## 6. 1152×648 响应式策略

- 顶栏区域宽度收紧，长文案省略号；按钮不出屏、不覆盖。
- 经营面板宽度按现有 clamp（278–340）不变；默认收起后城市可视面积显著增加。
- 抽屉内部可滚动。

## 7. 非目标

不重画城市/不新增美术；不做方格布局；不做贸易/武将/装备/外交/全图战；
不改战争、经济、人口、资源权威、存档 schema、建筑成本与数值；
不把战区/战时内城改成永久主城。
