# WORLD MAP V0

## 1. 阶段定位

`TXWZS-P1-WORLD-MAP-V0` 建立第一张可运行的外城战役地图 Graybox。

它的产品目标是让玩家在同一地理空间中看见：

- 玩家主城与敌方目标城；
- 城池、哨站、村庄和粮道节点；
- 两条可理解的河湾方向路线；
- 道路状态、玩家编队和关联任务；
- 返回内城与只读路线预览。

`b9719a5` 的 C0 横条战斗表现继续保留为规则、事务和自动测试入口。其技术实现通过，但该横条看板不是项目采用的外城或未来正式战斗产品形态。

## 2. 入口与场景关系

正式主场景仍是：

```text
res://scenes/blank_map.tscn
```

外城地图场景是：

```text
res://scenes/world_map_v0.tscn
```

玩家路径：

```text
内城
→ 选择现有城门
→ 进入战役地图
→ 查看节点、道路、编队和计划路线
→ 返回内城
```

本轮没有：

- 替换内城主场景；
- 删除告示板或 C0；
- 让告示板任务自动进入战役地图；
- 把战役地图接入战果或奖励事务。

## 3. 权威状态边界

### 3.1 真实读取

`ConstructionController` 继续是唯一城市运行时权威。只读投影读取：

- 当前日期；
- 可用步兵；
- 首战状态；
- 城市是否失守；
- 三项告示板任务的定义与当前进程状态。

### 3.2 固定地理配置

V0 的地图地理配置独立于运行时进度，包含：

- 地图尺寸；
- 五个节点的地图坐标、类型和基础归属；
- 五条道路的端点、绘制路径和初始状态；
- 河流、山地、平原与林地的 Graybox 表现。

这些数据不是 `CityState`、`BattleSession` 或正式存档字段。

### 3.3 非持久演示

当前项目没有正式世界地图编队坐标。V0 在黑石城附近显示一个明确标记为：

```text
NON_PERSISTENT_PRESENTATION_FIXTURE
```

的玩家编队位置。

其兵力摘要读取城市真实可用步兵，但位置、计划目标和路线预览只属于 UI 表现：

- 不推进日期；
- 不扣除粮草；
- 不触发任务；
- 不改变驻军；
- 不写 `FileAccess`；
- 不进入正式 save schema。

## 4. 地理布局

| 节点 | 类型 | 归属 | V0 位置关系 |
| --- | --- | --- | --- |
| 黑石城 | 主城 | 我方 | 地图西部，最醒目 |
| 北坡哨站 | 哨站 | 我方 | 黑石城北部高地 |
| 南部村庄 | 村庄 | 友好 | 黑石城南部平原 |
| 河湾粮道 | 粮道节点 | 中立 | 地图中央偏东，危险 |
| 河湾城 | 城池 | 敌方 | 地图东侧河湾处 |

道路：

| 道路 | 连接 | 状态 |
| --- | --- | --- |
| 黑石北道 | 黑石城 ↔ 北坡哨站 | 畅通 |
| 南部驿道 | 黑石城 ↔ 南部村庄 | 畅通 |
| 北岭旧道 | 北坡哨站 ↔ 河湾粮道 | 未侦察 |
| 河湾南路 | 南部村庄 ↔ 河湾粮道 | 危险 |
| 河湾东关道 | 河湾粮道 ↔ 河湾城 | 封锁 |

因此从黑石城到河湾方向存在北、南两条可读路线，最终都在河湾粮道汇合。

## 5. 表现与输入结构

```text
ConstructionController 真实只读状态
→ WorldMapPresentationModel
→ WorldMapController UI 选择
→ WorldMapCanvas 地图绘制
```

### `WorldMapPresentationModel`

纯只读 `RefCounted`：

- 构造节点、道路、编队和真实状态摘要；
- 映射中文归属、道路状态和任务状态；
- 确定性生成计划路线；
- 不访问场景节点；
- 不修改城市、任务、资源或战斗状态。

### `WorldMapController`

- 保存当前节点／道路／编队选择；
- 保存非持久计划路线；
- 进行世界坐标命中查询；
- 更新轻量侧边信息面板；
- 不声明 `_input`；
- 不创建 `BattleSession` 或战果事务。

### `WorldMapCanvas`

只负责地理 Graybox：

- 河流、山地、平原和林地；
- 道路实线／虚线／封锁符号与中文状态；
- 城池、据点、归属和任务标记；
- 玩家编队与计划路线高亮。

地图继续复用 `BlankMapRoot` 的唯一 `Camera2D` 和唯一 `_input`：

- 左键点击；
- 左／中／右键拖动；
- 滚轮缩放；
- `Esc` 先关闭面板，再返回内城。

## 6. V0 交互

- 点击节点：显示名称、类型、归属、状态、驻军边界和关联任务。
- 点击道路：显示起止点和中文状态。
- 点击编队：显示真实兵力摘要与非持久位置说明。
- 设为计划目标：高亮确定性道路序列，不执行行军。
- 回到黑石城：恢复黑石城附近镜头。
- 进入内城：仅黑石城可用。
- 查看关联任务：返回内城并打开现有告示板，不自动开始任务。
- 点击空白：取消当前选择。

禁用操作必须给出原因；不会显示自动胜利、失败、任务 ID、内部枚举或坐标调试按钮。

## 7. V0A 构图与标识修正

用户对首轮地图形态的结论为 `B`：

- 地理地图方向成立；
- 正式行军与编队移动继续冻结；
- 默认首屏、侧板遮挡和非颜色标识必须先修正。

V0A 采用以下规则：

### 响应式全览

- 全览边界由五个节点的世界坐标和节点／标签安全边距派生；
- 当前视口安全区决定缩放与中心，不写死 `1152 × 648` 专用坐标；
- 首次进入与“地图全览”都恢复五节点全貌；
- “定位黑石城”是独立操作，只负责把黑石城放到当前安全区中心。

### 侧板避让

- 侧板可见时，其左边界会从地图导航安全区中扣除；
- 选中节点、道路或编队后，如果对象落入侧板或安全边距，镜头只做必要平移；
- 关闭侧板不会恢复打开前镜头，因此不会制造二次跳跃；
- 侧板宽度和高度仅做局部压缩，没有改变 UI 架构。

### 非颜色编码

| 对象 | 非颜色编码 |
| --- | --- |
| 我方／敌方主城 | 城池轮廓、阵营旗帜、`〔我〕`／`〔敌〕` |
| 友好／中立节点 | 独立节点图形、`〔友〕`／`〔中〕` |
| 玩家编队 | 与城池不同的“军”字军旗 |
| 畅通道路 | 实线、`✓` |
| 危险道路 | 警示虚线、三角警示、`!` |
| 未侦察道路 | 点状虚线、未知圆标、`?` |
| 封锁道路 | 断裂虚线、阻断叉、`×` |
| 计划路线 | 浅色底衬、紫色虚线、方向箭头、“尚未出征” |

标签使用半透明底板提高道路上方的可读性，任务标记保持在节点名称之外。所有标签继续跟随世界对象，不显示内部 ID、坐标或调试字段。

## 8. 自动验收边界

`run_world_map_v0_smoke.gd` 覆盖：

- 五节点、五道路、唯一 ID、有效端点和无孤立节点；
- 黑石城／河湾城归属、河湾粮道危险状态；
- 四类道路状态；
- 投影确定性和无权威状态副作用；
- 非持久编队与真实兵力摘要；
- 节点、道路、编队命中；
- 空白取消、拖动分流、UI 防穿透、缩放上下限；
- 回到黑石城、Esc 面板／返回顺序；
- 1152×648、1280×720、1920×1080 布局边界；
- 三种分辨率下默认全览包含五节点安全边距；
- 侧板打开后河湾城仍位于未遮挡地图区域；
- 全览／定位黑石城按钮语义和恢复结果；
- 四种道路状态具有不同线型和符号；
- 计划路线明确标为非持久、尚未出征；
- 没有第二个 `_input`、`CityState`、`BattleSession` 或存档写入。

自动测试和 AI GUI smoke 不能替代用户判断：

- 它是否真的像一张地理地图；
- 五个节点是否十秒内可理解；
- 两条路线是否自然；
- 标签、道路和侧板是否拥挤；
- 拖动、缩放和点击是否顺手。
