# P0-06 统一建筑交互壳阶段验收

- 日期：2026-07-25
- 状态：`ACCEPTED_AS_P0_STAGE_BASELINE`
- 用户结论：接受当前结果作为 P0 灰盒基础阶段的封存版本，并授权进行代码整理、提交和 GitHub 备份。

## 本阶段纳入基线

- 六个固定灰盒建筑和运行时测试建筑使用同一份权威记录结构。
- 固定建筑与运行时测试建筑共用选择、描边和右侧详情面板。
- 固定建筑可选择、不可移除、不可移动。
- 运行时测试建筑保留 P0-05 的选择与安全移除闭环。
- 建造入口移至右侧，只提供一个中性测试建筑模板。
- 原底部 `ContextBar` 及其临时入口和无功能占位已删除。
- `MapWorld`、`Camera2D`、根 `_input` 所有者和既有导航规则保持唯一。

## 证据边界

- 用户接受的是当前阶段整体结果。
- 本记录不将阶段接受扩写为完整逐项实体鼠标测试，也不伪造用户未提供的逐项观察。
- 自动 smoke 用于验证统一记录、固定建筑能力、选择／详情、右侧建造 UI、防穿透、固定占用和 P0-05 回归。
- 自动构造输入仍只是辅助证据，不能替代未来涉及实体鼠标手感的人工验收。

## 明确不包含

- 建筑移动、批量或连续移除、撤销／重做、资源返还。
- 道路、生产、升级、存档、多城市、军事玩法和军令台功能。
- 正式建造菜单、正式建筑数据、正式视觉和美术资产。
