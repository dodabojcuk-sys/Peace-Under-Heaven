## 6. 平衡模拟

C0 实现后至少模拟：

1. 20、30、40、50 名步兵分别在第 1／5／8／10／12 日进攻；
2. 1、2、3 小队；
3. 全正门、全侧门、分兵；
4. 无将领、先锋官、守备官、辎重官；
5. 有／无队列操练；
6. 供给正常／不足；
7. 立即撤退、接敌后撤退、坚守再前进；
8. 检查“正门高门低守军”和“侧门低门高守军”是否存在不同投入下的取舍，而非一条路线全面占优。

输出：

- 结果；
- 结束 tick；
- 伤亡；
- 突破路线；
- 命令序列；
- 是否存在单一无脑固定操作明显统治所有快照。

数值不合理时可以调 V0 参数，但不能用隐藏随机或固定成功掩盖问题。

- 自动 runner 证明契约、事务和确定性，不证明操作节奏好玩；
